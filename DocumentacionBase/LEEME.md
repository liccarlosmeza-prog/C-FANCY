# C’FANCY  Identidad y especificación versión 04

Paquete de trabajo del 28 de octubre de 2026. Propuesta para revisión de la propietaria y preparación del desarrollo. Abre primero Guia_integrada.docx; para ver la propuesta visual consulta 06_Visuales. Este ZIP contiene documentación y datos de prueba, no una tienda funcional ni una API desplegada.

## Orden sugerido
1. Revisar identidad, paleta y decisiones con la propietaria.
2. Comparar las láminas de marca, inicio y producto con los tokens.
3. Revisar los diez productos de ejemplo y sustituirlos por datos reales.
4. Usar Backlog.csv, Pantallas_y_flujos.md, Diccionario_de_datos.csv y openapi.yaml para implementar las 14 tareas adjuntas.

## Carpetas
- 01_Marca: identidad editable en Markdown, tokens JSON y CSS.
- 02_Catalogo: diez fichas, datos JSON/CSV, categorías y colecciones.
- 03_UX: pantallas, estados, navegación, responsive y reglas de interacción.
- 04_Desarrollo: contrato API OpenAPI, backlog, modelo de datos y guía técnica.
- 05_Validacion: casos de prueba y controles de liberación.
- 06_Visuales: imágenes de propuesta, logo reconstruido y notas de uso.
- 07_Referencias: fuentes del propietario y bases técnicas.

## Estado y límites
Las tareas se encuentran especificadas, NO implementadas. Los casos de prueba de la aplicación están NO ejecutados. La verificación de este paquete solo comprueba consistencia de archivos y diseño del documento. Todos los productos son is_demo=true. No publicar precios, inventario, materiales, plazos ni garantías ficticios. No se ha generado un certificado gemológico. Audio no transcrito por acuerdo de continuar con las imágenes escritas. Se propone ampliar los seis colores anteriores con base marfil; requiere aprobación.

Los mockups son imágenes raster conceptuales. Si difieren de un valor del catálogo o un token, los JSON y la documentación son la referencia para implementar. El logo reconstruido no sustituye al original vectorial del propietario. Fuentes tipográficas propuestas, no incrustadas. No hay credenciales ni datos personales reales en las fixtures.
