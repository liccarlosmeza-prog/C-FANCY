# Documentación de contexto · C’FANCY

Incluida con **Carga-1**. Esta carpeta conserva documentación de marca, catálogo ilustrativo, UX, datos, investigación de mercado, marketing, backlog, sprints y referencias visuales. No es código ejecutable del sitio.

## Orden de lectura

1. [Plan de marca y negocio](archivos%20base/01_Plan/01_PLAN.md).
2. [Investigación de mercado](archivos%20base/01_Plan/02_INVESTIGACION_DE_MERCADO.md) y [marketing](archivos%20base/01_Plan/03_MARKETING_90_DIAS.md).
3. [Datos y catálogos](archivos%20base/02_Datos/01_MODELO_DE_DATOS.md).
4. [Backlog](archivos%20base/03_Scrum/01_BACKLOG.md) y [sprints](archivos%20base/03_Scrum/02_SPRINTS.md).
5. [Replanificación implementada](../docs/PLAN_POR_PROCESOS.md), [estado actual](../docs/ESTADO_BACKLOG.md) y [guía del sitio](../docs/GUIA_DE_USO.md).

`01_Marca`–`07_Referencias`, la guía integrada y `LEEME.md` conservan la propuesta inicial. Sus afirmaciones históricas de «no implementado», contratos propuestos y listas no ejecutadas describen aquel paquete; para la aplicación actual prevalecen el código, las pruebas y `../docs/`.

No se incluyen skills ni paquetes de agentes. Las menciones históricas a esas herramientas no significan que formen parte del repositorio. El audio original sin transcripción tampoco se incluye porque no se utilizó como requisito documental.

Esta carpeta está fuera de `public/` y de la salida Vite, excluida por `.dockerignore` y no se copia a la imagen final del servidor. No requiere un despliegue separado ni cambia las rutas de la aplicación. El repositorio es público: estos archivos son consultables en GitHub como contexto.
