# Uso de visuales

Las láminas son propuestas raster generadas para revisión. No son un sitio funcional, un catálogo real ni una prueba de materiales. Productos y especificaciones son ficticios. Si una lámina difiere de los datos o tokens escritos, implementar desde los JSON y la documentación.

logo_reconstruccion_no_maestro.png reproduce aproximadamente la bolsa desde una fotografía. No se entrega como SVG ni como vector original; solicitar archivo maestro a la propietaria antes de impresión. No inventar certificaciones a partir de un dibujo de diamante.

Las tipografías propuestas se indican en los tokens; no se distribuyen archivos de fuentes ni se garantiza que el raster utilice exactamente sus contornos. Deben cargarse y verificarse al implementar.
